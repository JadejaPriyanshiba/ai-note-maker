  • Degenerates to O(n) if the tree is unbalanced

What it does

One roadmap, every study format

Approve a topic breakdown once — everything below is generated from it, and stays consistent with what you're actually studying.

AI Study Notes

Describe a subject, approve an AI-suggested topic roadmap, then get rich structured notes — headings, callouts, tables, code blocks, and exam-tag highlights — generated topic by topic.

Practice Tests

Auto-generated MCQ, true/false, and fill-in tests, with a weak-topic dashboard that targets retests at what you're actually missing.

Teach-Back Mode

Explain a topic in your own words. The AI grades your understanding and points out what you missed or got wrong.

Flashcards

AI-generated decks with spaced-repetition scheduling, so due cards resurface automatically.

Audio Learning

Turns a note into a two-host, podcast-style dialogue script for listening-based review.

Shorts Learning

Breaks a topic into an AI-generated learning tree and feeds you short, curated YouTube videos per node.

Collections

Nest notes, decks, and tests into folders the way you'd organize a semester.

Community

Publish notes, decks, or whole collections publicly, and remix anyone else's.

Local-first, cloud sync optional

Every note, deck, and test attempt is written to the browser first — the app is fully usable without an account. Sign in and it additionally syncs to a private, per-user Firestore database enforced by security rules. Nothing is shared unless a user explicitly publishes it to the Community.
